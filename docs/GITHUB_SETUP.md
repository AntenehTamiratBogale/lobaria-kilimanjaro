# Repository access

Repository: https://github.com/AntenehTamiratBogale/lobaria-kilimanjaro

Clone it with:

```sh
git clone https://github.com/AntenehTamiratBogale/lobaria-kilimanjaro.git
cd lobaria-kilimanjaro
```

The repository was created by the owner with public visibility. The analysis code, processed inputs, shared draw indices and selected reference results are tracked at the repository root. Generated analyses and JPG figures are excluded by `.gitignore`.

See the root README for dependency installation and execution. Before a manuscript release, finalize dataset accessions, the publication citation, author metadata, reuse licensing and validation of the latest figure revisions.
