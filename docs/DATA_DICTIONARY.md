# Processed input data

| File | Meaning | Main identifiers |
|---|---|---|
| `input/amplicon_16S_asv_TZ_AU.csv` | Processed ASV read counts; rows are ASVs, columns thalli | ASV row names and metadata `id` |
| `input/amplicon_16S_tax_TZ_AU.csv` | Taxonomic assignments for the ASVs | Matching ASV row names; Kingdom through Genus |
| `input/meta_data_TZ_AU.csv` | Sample and population metadata | `id`, `group`, `replicate`; sampling descriptors |
| `input/metaproteome_TZ_AU.csv` | Processed protein groups, functional/taxonomic annotations and per-thallus NSAF | `pg`, `og`, `subRole`, `mainRole`, taxonomy and metadata sample columns |

The CSV inputs are preserved byte-for-byte from the earlier analysis package. `docs/source_provenance.json` records their checksums. Dates and other author-supplied metadata are included as provided; unresolved collection-date discrepancies have not been silently corrected.

`python_results/` contains reference calculations plus common one-based permutation and bootstrap draw indices. Its `protein_OLS_validation_only.csv` is an independent coefficient check, not empirical-Bayes limma inference. Native model output is generated by R.

`reference_results/native_R/` contains selected previously completed results. It is deliberately separate from the generated `R_results/` directory so reference tables cannot be mistaken for a new run.
